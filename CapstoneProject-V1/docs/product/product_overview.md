# Product Overview — FlowTask Mobile App

## What is FlowTask?

FlowTask is a B2C productivity app for iOS and Android helping individuals and
small teams organise tasks, notes, and projects. It targets knowledge workers,
students, and freelancers who need a lightweight but powerful task manager with
reliable cross-device sync.

**Current active users:** ~10,000
**Supported platforms:** iOS 15+ and Android 12+
**Current stable version:** 3.1.0

## User Personas

**Alex — The Busy Professional**
Works in project management. Relies on FlowTask to manage deadlines across
multiple projects. Uses the app 10-15 times per day. Cares deeply about
reliability, sync speed, and offline access.

**Maya — The Student**
Uses FlowTask to track assignments, reading lists, and exam schedules. Accesses
the app primarily on iPhone. Values simplicity, a clean UI, and free-tier
features. Price-sensitive.

**Jordan — The Freelancer**
Manages client projects across multiple devices. Uses premium features: file
attachments, recurring tasks, and the analytics dashboard. Needs stable sync
between phone, tablet, and laptop.

## Core Value Proposition

- **Single source of truth** for tasks across all devices
- **Instant sync** — changes appear on all devices within 5 seconds (when online)
- **Clean, distraction-free UI** — no feature bloat
- **Offline-first** — full read/write access with background sync when reconnected

## Business Model

| Tier | Price | Features |
|------|-------|---------|
| Free | $0/month | Up to 50 tasks, basic sync, limited file attachments (5MB) |
| Premium | $8/month | Unlimited tasks, priority sync, 1GB attachments, analytics, team sharing |
| Team | $15/month per user | All Premium + real-time collaboration, admin panel, audit logs |
